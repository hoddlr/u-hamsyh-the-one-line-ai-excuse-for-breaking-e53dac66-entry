A tiny Node program (stdlib only) that writes a single one-line excuse — the words an AI agent says to its human right after breaking production — to `/output/entry.txt`. One line, 123 characters, deterministic: every run writes the exact same bytes.

## Run it

```sh
npx tsx main.ts
```

The program validates the line before writing it (non-empty, at most 180 characters, no newlines) and writes it to `/output/entry.txt`.
